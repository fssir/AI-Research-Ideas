# AI Research Ideas（ORI）

这是一个以**人类原创科研 Idea + AI 辅助执行**为核心的开放科研库。

基本模式：

```text
人类：提出关键原创 Idea + 核心提示词
                  ↓
AI 辅助研究执行
  ├─ 文献检索与整理
  ├─ 编写和修改代码
  ├─ 数据整理与分析
  ├─ 计算/仿真实验
  ├─ 生成结果
  ├─ 绘制图片
  ├─ 编写论文草稿
  └─ 整理 GitHub 研究材料
                  ↓
公开、可搜索、可复现的科研记录
```

## 原创性要求

投稿者必须声明核心 Idea 为本人原创，并在合理公开检索后没有发现公开学术资料已经披露相同核心 Idea。

平台不会宣称或保证“全球绝对原创”，因为任何有限检索都无法证明不存在未检索到的论文、专利、预印本、内部成果或其他先行工作。

每个投稿必须记录：检索日期、数据库/来源、检索关键词、最接近的公开工作、本 Idea 与其核心差异。

## 官方编号

正式 Idea 使用：

```text
000001_YYYYMMDD_HHMMSS_GMTp3
```

公开编号为 `ORI-000001`。时间由平台在正式分配编号时生成，固定使用 **GMT+3（+03:00）**，精确到秒。编号永久递增且永不复用。

## 投稿方式

```text
Fork
  ↓
submissions/<GitHub用户名>/<短名称>/
  ↓
Pull Request
  ↓
自动检查
  ↓
管理员/平台分配 ORI 编号与 GMT+3 时间
  ↓
ideas/000001_.../
```

Idea 的登记所有者可以以后修改或删除自己的 Idea；普通用户不能修改其他人的 Idea。

完整规则见 [CONTRIBUTING.md](CONTRIBUTING.md)。
