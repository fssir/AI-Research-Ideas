# AI Research Ideas

**[Browse Ideas](ideas/) · [Submit an Idea](https://github.com/fssir/AI-Research-Ideas/issues/new?template=new_idea.yml) · [中文说明](.github/docs/README.zh-CN.md)**

An open library built around **human research ideas and prompts**, with large language models and other tools used to develop literature reviews, code, data analyses, experiments, figures and manuscripts. An initial idea or a complete research package is welcome.

## Browse and search

Open **[ideas/](ideas/)** to see newest-first titles, summaries, suggested research fields and keywords. Click a title to inspect its complete folder; code, papers, data and figure links appear when those materials exist.

For all Markdown content, use GitHub **Code** search, for example:

```text
repo:fssir/AI-Research-Ideas path:ideas/ "irrational"
```

The [machine-readable catalog](.github/ori/index/ideas.json) includes the full text and source hashes of the indexed Markdown files, not just summaries. Classification is transparent, rule-based and can be imperfect. Inclusion in this catalog does not guarantee indexing by Google, other search engines or AI services.

## Contribute

**One nonempty Markdown file is enough.** Start with the submission link above; the platform generates your numbered folder and README. Then upload any code, data, papers or figures into that folder through a PR. No separate submissions directory or metadata form is required. [Upload/edit guide](.github/CONTRIBUTING.md).

Published folders keep permanent sequential IDs and second-resolution fixed GMT+3 timestamps, such as `000001_20260908_151012_GMTp3`. Authors can update or delete their own entries; deleted IDs are not reused. Maintainers retain upstream administration, while everyone may fork and reuse the material.

## Research integrity

Submit ideas you genuinely believe are original. The repository does not certify novelty, patentability, peer review or research correctness. The hosted automation organizes and validates submissions; it **does not execute submitted research code or autonomously conduct experiments**. AI work must be performed with appropriately authorized models/tools and its actual execution disclosed. Never present invented data or unrun experiments as completed results.
